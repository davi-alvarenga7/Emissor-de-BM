# Emissor de BM — execução

1. Instale Python 3.11+ (python.org, marque "Add to PATH").
2. Neste pasta, rode:
   ```
   pip install -r requirements.txt
   python app.py
   ```
3. Banco `bm_system.db` é criado sozinho na primeira execução (SQLite, SQL).

Ordem das colunas no lote de empresas:
Razão Social | CNPJ | Código PO | Início PO | Fim PO | Valor Total PO | Objeto | E-mail contato | Valor Hora | Responsável | Usuário E-clic
